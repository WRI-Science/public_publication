Structure Loss Pipeline · release history

Release history

This project publishes a building-loss dataset: one row per building per fire, saying whether that building was destroyed. Each published version is frozen and keeps its own version number, so an analysis can name exactly which data it used. This page lists every version, what it covers, and how wide its schema is. The current version is v0.9.0, released 13 September 2026: 377 fires, 2,069,752 rows, 68 columns.

how to use this page

Versions are frozen; newer is wider, not different

A published version is never edited. Later versions add fires, add rows, or add columns; they do not silently change the values already published for a building that was already there. If you are starting a new analysis, take the most recent version. If you are reproducing a published result, take the version that result names.

Two things are counted in the table below. Rows is one building in one fire as described by one source, so a fire covered by two independent sources contributes two sets of rows and you must not add them together. Columns is the width of the schema: how many attributes each row carries.

the companion dataset

The historical companion

A second, smaller dataset is published beside the main one: the hand-assembled historical record of buildings destroyed in United States wildfires between 2002 and 2022, enriched with per-building attributes measured from imagery by this project. It has its own version numbers.
