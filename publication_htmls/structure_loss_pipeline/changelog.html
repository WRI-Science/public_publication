Structure Loss Pipeline · history

What changed

Every other page on this site describes the dataset as it is now. This one is for anyone who read an earlier version, or an earlier number: the decisions that changed what the dataset contains or what its figures mean, newest first, one line each.

The short version

If you are holding numbers from before 13 September 2026, replace them. A defect in how satellite pixels were read moved most damage features; the frame that decides which buildings a fire contains changed; radar left the model; and the dataset went from five fires of the historical record to all 361 of it. Nothing published before that date carries over unchanged.

the record

Decisions a data user would notice

Newest first. The full technical entry for each is in the project change log, under the date given.
DateWhat changedWhy it matters to you
2026-09-13 A second model's call arrives beside the first Most scored rows now carry a third loss call, from a model that reads a clean before-and-after pair of annual composites — one year wholly before the fire, one wholly after. That pair only exists once the year is over, so the call is later than the 74-day one and cannot replace it. On the rows that carry both, it is worth +6.1 points of recall for 1.6 of precision and +0.021 pooled F1 on an interval that excludes zero. The primary call is byte-identical to the previous release. Where the second call cannot be made the column is null with a stated reason, never partial, and it is null throughout the hand survey's half.
2026-09-13 The last big retrospective fire lands, and nothing moves Dixie 2021 — 3,959 km², the largest frame in the cohort — is the seventeenth fire the hand survey covers that this pipeline has now also enumerated. It brings 8,990 structures and 1,156 destroyed calls, and its own numbers are among the best in the set. No published bound moved: the detection range is still 0.588–0.912 and the precision range still 0.831–0.963, while the end-to-end destroyed ratio went 0.764 to 0.769. One admitted fire is still out, and no amount of compute fixes it — Erskine 2016's county has no footprint dated before the fire.
2026-09-13 A wrong flag corrected, and the build's own record finally ships The column saying whether a building owns any 60-centimetre raster cells was set from the shape it was given rather than from the cells it ended up with, so it read 39,646 where the truth is 114,659. It is corrected, and the count behind it now ships as its own column. Separately, the build stage's manifest was being written and then silently overwritten by the package's: both now ship, and the file table in the data descriptor is accurate for the first time. No row, fire or loss call changed.
2026-09-12 Sixteen of the survey's own fires are now described twice The 2016–2022 era stops being "capable, not done": sixteen fires the hand survey already covers have been run through this pipeline as well and are rows in the file beside the survey's own. The row unit is now (fire, source) and the two descriptions of a dual-source fire must never be summed — neither is a subset of the other. Group by fire and source; a pooled count over an era picks one. The building identifier is namespaced per source and a test enforces it. In the same release every one of the survey's 1,770,939 rows gained nine geometry columns at 100.0000 % join coverage, and South Fork NM joined the modern half.
2026-09-12 The advisory loss call is scoped to the near-perimeter zone The second, advisory destroyed call now takes each fire's threshold from the perimeter-plus-100 m population instead of the whole inventory. Its per-fire thresholds moved from a 0.158–0.792 range to 0.601–0.792 and it calls 15,951 structures destroyed rather than 17,362. The primary call did not move at all.
2026-09-12 The dataset carries the whole historical record 361 fires and 1,770,939 rows of the 2002–2022 survey, verbatim, where earlier versions carried only the five fires that happened to be cached. If you joined on a building identifier, note that four fires' identifiers changed: they are now enumerated per fire over the national release.
2026-09-12 Radar left the damage model The model is optical only. Radar had been promoted under a rule written in advance; on corrected feature tables it no longer cleared that rule, so it was removed. Removing it costs nothing measurable and lets the model run on fires from before the radar archive opened.
2026-09-12 Two flag columns on the historical half The survey's own release repeats 20,296 rows exactly, and 18.3 % of its rows sit at a location a second fire also claims. Both are now flagged per row rather than silently cleaned. De-duplicate on geometry before any pooled count. This is a separate trap from the dual-source rule above, and both apply.
2026-09-12 A second loss call ships beside the first Every scored row now carries two calls: one at a fixed threshold and one at a per-fire threshold. Use the fixed one to classify buildings and the advisory one if you are counting them — and say which you used.
2026-09-11 The licence is settled MIT for the code, CC BY 4.0 for the data. Rows whose geometry came from an ODbL-licensed footprint layer are dropped from the released package — 32,910 rows, 1.57 % of the build, unevenly distributed and heaviest on rural fires. None of the survey's own rows is touched. No DOI has been minted yet.
2026-09-11 An attribution rule for overlapping fires When two fires reach the same building inside each other's observation windows, one rule decides which fire may claim it. Structures called destroyed under two fires went from 271 to 0. Rows ceded to a later fire carry no damage call and say why.
2026-09-10 The frame became the fire's public perimeter Which buildings a fire contains is now decided by its published perimeter plus a ring, matching the historical survey's own rule. It replaced a buffer drawn around inspection points, which enumerated a different population and could not define a fire at all in a state with no inspection programme. It added roughly a third again as many structures and moved no accuracy figure.
2026-09-10 A satellite sampling defect was found and fixed The one that invalidates old numbers. The read window that pulls reflectance for a building could disagree with the coordinates indexing it by one pixel, and the cloud mask was read at a different padding from the bands it masked — so a building's cloud verdict could come from a different pixel than its reflectance. At least one feature changed for 85 % of buildings in the 10 m tables and 51 % in the 30 m ones. Every table was rebuilt and every model refitted.
2026-09-10 The building detector was frozen Detector work stopped at one checkpoint so that later comparisons are about the damage model rather than about a moving inventory.

Source: logs/CHANGELOG.md in the project repository, the dated entry for each row, and docs/release-notes.md. Each entry carries the measurement behind the decision and the commit that applied it; the experiment ledger (docs/experiment-ledger.md) carries one row per idea, experiment and data source, including the ones that failed.
