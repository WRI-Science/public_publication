Structure Loss Pipeline · how certain

How certain are these numbers?

This project estimates, building by building, which structures a wildfire destroyed, using free satellite imagery and public maps of building outlines. Every accuracy figure it publishes is an average taken over a modest number of fires — and it is fires, not buildings, that the figure is really uncertain about. This page attaches an interval to every headline, explains in plain terms how that interval is built, and says what it does and does not promise.

What this page shows

The single number to take away: against California's door-to-door damage inspections, the model's destroyed calls score an F1 of 0.9158, with a 95 % interval of [0.8591, 0.9190] across fires. F1 is one number combining precision (what share of the buildings we called destroyed really were) and recall (what share of the real destruction we found); it is their harmonic mean, so a model cannot buy a good score by sacrificing one for the other.

That interval is wide, and it is wide for an honest reason: it rests on eight inspected fires, two of which hold 84 % of the buildings between them. The width is a statement about how much evidence exists, not about the arithmetic — no better estimator narrows it.

Every interval here is produced by resampling whole fires from per-building predictions already stored on the data share. No model is retrained anywhere on this page. All rows use the same fixed decision threshold: the model gives each building a probability of having been destroyed, and we call a building destroyed when that probability is above 0.85, a value fixed in advance and never tuned fire by fire.

01 · reading the intervals

Why the uncertainty is about fires, not buildings

582,554 buildings sounds like an enormous sample, and it would be if each building were an independent trial. It is not. Those buildings sit inside 66 fires, and the buildings within a single fire share almost everything: the same weather and wind, the same vegetation and terrain, the same satellite images on the same dates, the same inspection crew recording the outcome. If the model reads one fire well, it tends to read nearly every building in that fire well; if it misreads a fire, it misreads thousands of buildings at once. Counting each building as its own piece of evidence would therefore produce an interval far narrower than the evidence deserves.

The question a reader actually has is how would this perform on the next fire. That is a question about the sample of fires we happen to have, so the fire is the unit that gets resampled.

How the interval is built: a cluster bootstrap over fires

The recipe is short enough to state in full.

  1. Start from the fires that were scored, each carrying all of its own buildings and their stored predictions.
  2. Draw a new set of fires of the same size at random with replacement, so some fires appear twice or more and others not at all.
  3. Recompute the headline figure on that set exactly as it was computed on the real one.
  4. Repeat 2,000 times, giving 2,000 alternative versions of the headline.
  5. Sort those 2,000 values and read off the 2.5th and the 97.5th percentile. That pair is the 95 % interval printed beside the estimate.

Because the thing being drawn is a whole fire — every building it contains, kept together — this is a cluster bootstrap, the cluster being the fire. Keeping the cluster intact is what stops the correlation between buildings in the same fire from being mistaken for independent evidence.

What the interval says, and what it does not

It says: had this work happened to cover a different draw of fires from the same pool, the headline would usually have landed somewhere inside this range. It is a measure of how much the number depends on which fires we got.

It does not say anything about a single building, and it is not a range for one fire's own score. It also cannot capture a bias shared by every fire: if the ground truth itself is wrong in a consistent direction, every resample inherits that error and the interval stays silent about it. And it describes the pool of fires sampled here — mostly California, mostly recent — not fires of a kind that pool contains none of.

Pooled and mean-per-fire

Two ways of averaging appear throughout, and they answer different questions. Pooled tips every building from every fire into one heap and computes the score once, so the largest fires dominate; it answers "across all the buildings covered, how accurate was the result". Mean per fire computes the score separately for each fire and then averages those scores, so a fire with three hundred buildings counts as much as one with eighteen thousand; it answers "on a typical fire, how accurate is this". Pooled scores are the higher of the two here, because the very large fires are the ones the model reads best. Both are published, always side by side.

⚠️ There are two kinds of interval on this site and they are never mixed in one cell. A fire-level interval resamples the fires and answers "what would this be on the next fire"; that is the one a reader generalising from these results needs. A within-fire interval resamples one fire's own buildings and says only how precisely that fire was measured; it generalises to nothing. Every table on this site states which of the two it is showing.

02 · the headlines

Two independent answer sheets are used. The first is a published, hand-assembled record of buildings destroyed in United States wildfires, one point per destroyed building, compiled by Carlson and colleagues. The second is CAL FIRE's damage inspection programme, in which inspectors visit each structure after a fire and record whether it was destroyed, damaged or untouched. Three terms in that table, defined once. AUC is the probability that a randomly chosen destroyed building is given a higher score than a randomly chosen surviving one, so it measures ordering rather than any particular threshold. Average precision summarises how precision falls away as recall is pushed higher, across all thresholds at once. The last two rows concern our building detector, a neural network trained on aerial photography that finds buildings the public footprint databases have missed; a ground-truth point and one of our building locations count as the same building when they lie within 10 m of each other, matched one to one.

Precision and recall are simply the four cells of a confusion matrix rearranged. The full matrices, in counts and in percentages, are on the confusion matrix page.

⚠️ Look at the pooled F1 interval: [0.859, 0.919] against an estimate of 0.9158. It barely reaches above the estimate. That asymmetry is real, not an error: Eaton and Palisades are 84 % of the buildings and both score high, so a resample that happens to draw either of them less often falls, while one that draws them more often has almost nowhere left to rise. The interval is skewed because the evidence is.

The randomness of the procedure is negligible next to the randomness of which fires exist. Repeating the whole resampling with different random seeds moves pooled F1 by less than 0.001 — 0.9158 / 0.9154 / 0.9152 / 0.9158 — while dropping or duplicating a single fire moves it by around five hundredths. A ninth fire lives in the second kind of variation, not the first.

04 · calibration

The probability is a ranking, not a frequency

against both answer sheets

The model gives each building a number between zero and one. A separate question from "does it rank the burned buildings above the surviving ones" is "does that number behave like a frequency" — if you gather every building the model scored around one in five, did about one in five of them really burn?

A reliability diagram, also called a calibration curve, answers exactly that. Sort every building by the score it was given, cut the sorted list into ten groups holding equal numbers of buildings, and for each group plot the average score on the horizontal axis against the share that were really destroyed on the vertical axis. Perfect agreement puts the points on the diagonal. A point below the diagonal means the model claimed more confidence than the outcomes justified — over-confident. A point above it means the opposite.

Source: calibration_pooled.csv for each run, under outputs/uncertainty/ on the data share, rows for ten equal-count groups pooled across fires. Twenty-group versions and per-fire curves sit in the same folders.

Source: calibration_ci.csv for each run, under outputs/uncertainty/ on the data share (2,000 resamples, ten groups), with the accompanying summary.json; the maximum calibration error is the largest absolute group gap in calibration_pooled.csv. Expected calibration error is the average gap between predicted probability and observed frequency, weighted by how many buildings fall in each group; maximum calibration error is the largest single such gap; the Brier score is the mean squared difference between the probability given and what actually happened, so lower is better. The correction takes expected calibration error 0.0514 → 0.0005 against the historical record and 0.0651 → 0.0071 against the inspections, with Brier 0.0328 → 0.0208 and 0.0729 → 0.0616.

The better-calibrated answer sheet is not the better-ranked one — which is the clearest sign that the score is an ordering rather than a frequency. The inspected fires rank at AUC 0.974 while calibrating at an expected error of 0.065; the 66 fires of the historical record rank at 0.986 and calibrate at 0.051. The correction used is isotonic regression: a curve fitted to map raw scores onto observed frequencies, constrained to never go downhill, so it can rescale scores but can never reorder them. A corrected column, destroyed_prob_calibrated, ships beside the raw destroyed_prob rather than in place of it, and the decision threshold stays on the raw score: moving it onto the corrected axis would change the published product without adding any evidence, and costs 0.0017 of pooled F1 at the matched operating point.

A correction curve is not a per-fire threshold rule. The curve is fitted each time on the other 65 of the 66 fires, so it comes out nearly identical every time: the raw score at which the corrected column reaches 0.5 spans only 0.875–0.894 across the 66 fires of the historical record, while the best threshold chosen with hindsight for an individual fire ranges from 0.20 to 0.93. A rule that does adapt to the fire is described on the beyond-California page.

05 · limits

What these intervals cannot tell you

Every accuracy figure on this site is held-out: the model scoring a fire was trained only on the other fires, so no fire is marking its own homework. What that does not amount to is a forecast tested after the fact — each of these fires had already burned and been inspected when the model was built, so the numbers describe performance on unseen fires of a kind already represented here, not on a fire nobody had seen at all.

Three further limits follow directly from the method described at the top of this page. An interval built by resampling fires can only reflect the fires in the pool, so it does not extend to landscapes, building stocks or fire behaviour absent from it. It cannot widen to account for an error the ground truth makes consistently in every fire. And with eight inspected fires, two of them holding 84 % of the buildings, any interval computed over them is coarse by construction — which is why both the pooled and the one-fire-at-a-time versions are always published together rather than a single figure standing alone.
