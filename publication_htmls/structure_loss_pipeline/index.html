what this is

The project in four paragraphs

The USGS structure-loss dataset is a per-building census of what wildfires destroyed in the continental United States between 2002 and 2022 — 361 fires, 1,770,939 buildings, hand digitised. It is the reference layer for anyone modelling wildfire exposure, and it stops at 2022. This project continues it with a pipeline that uses public data only: aerial imagery and two public footprint databases to enumerate the buildings that stood before a fire, then before-and-after satellite imagery at each building to decide which of them burned.

The two halves are judged separately, against different answer sheets, because they are different mistakes. The list of buildings is scored against the hand survey's census — which enumerates every major building inside a fire's footprint, so a missing building is measurable. The loss call is scored against fire-service inspections of fires that happened after the survey ends, which is the only truly out-of-sample evidence that exists. The honest summary of the first half is that the public footprint databases are the product and our detector is slightly better than them. The honest summary of the second is that the loss call is good, and that the evidence behind it is eight California fires, two of which hold most of the buildings.

The output is one file on one schema, one row per building per fire, with the survey's rows and ours side by side and a field only one era can fill left null on the other rather than back-filled. Every row carries a continuous destroyed probability, the threshold behind the call, where the building sat relative to the fire perimeter, and which layer found it and which model scored it. MIT for the code, CC BY 4.0 for the data.

Two rules shape everything here. No attribute of the fire itself ever reaches the model — not size, perimeter, burn severity, region, state or year — so a loss call is never a restatement of the fire's own attributes; perimeters decide where to look and never what to predict. And every promotion bar is written down before the number that would clear it is measured, which is why this site publishes results that point away from what shipped: a component of the model that stopped clearing its own rule and was removed because of it, and a threshold rule that cleared a pre-registered bar, was adopted, and then did not transfer to the product — so it ships as a second column with the reason written down rather than quietly replacing the first.

status

Where the project is, 13 September 2026

The published dataset is v0.8.0, cut on 2026-09-13 and committed. The 2016–2022 era has stopped being "capable, not done": seventeen fires the hand survey already covers have now been run through this pipeline as well — every fire that was ever admitted except one — and each of the survey's 1,770,939 rows carries a building polygon. Every number on this site is transcribed from a file the pipeline wrote, and the source line under each table names it.

Three caveats a first-time reader should carry.

  • Two loss calls ship on every row, and the second is advisory. The per-fire threshold rule cleared a pre-registered bar on a table of inspected structures and then failed on the product population, so it is a second column rather than a replacement — the deep dive tells that story, and it is the most important caveat on this site.
  • A count from this pipeline is not a count from the hand survey. Run end to end on seventeen of the survey's own fires it reports about 0.77 of its destroyed count, that factor runs 0.48 to 1.80 fire to fire, and it is a net of a large miss and a large addition — running the pipeline backwards. Those seventeen fires are now in the file twice, once per method, and the two descriptions must never be summed.
  • Most rows now carry a third, later loss call. A second model reads a clean before-and-after pair of annual composites, which only exists once the year is over, and finds six more points of recall for one and a half of precision. It is a separate column, never an edit to the first — the deep dive has it.
  • Nothing here is a forward hold-out yet. Every damage figure is cross-validated or leave-one-fire-out. The fix is time, and it waits on the next inspection archive.
