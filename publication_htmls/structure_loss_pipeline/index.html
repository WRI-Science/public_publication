What this is

The Structure Loss Pipeline extends the USGS Carlson structure-loss record (2002–2022) to the present using public data only. It does two things in order: it finds the structures that stood before a wildfire — USA Structures footprints plus a U-Net run on 0.6 m NAIP aerial imagery — and then predicts which of them were destroyed, from before / after Sentinel-2 and Landsat reflectance at each building. Every map below is one fire, drawn on satellite imagery so the predictions can be judged by eye rather than taken on trust.

The two recall numbers

Detection accuracy is reported twice, and the pair is the point. Recall is the product number: of the buildings Carlson recorded, how many did the pipeline find? Recall given the point is inside a label is the model number: of Carlson's buildings that were actually inside a USA Structures training polygon, how many did the network find? An early version of this pipeline reported 55 % recall, which turned out to be 88 % on labelled buildings and 6 % on unlabelled ones — a label-coverage result reported as a model result. Both are shown so nobody tunes the network to fix the labels.

Reading the maps

  • Each map opens on a dense detail window. The Jump buttons move between windows; the fire-wide grid button zooms out and turns on a coarse grid covering every point in the fire.
  • The circled i at the top left opens a plain-language explainer: a glossary, what each layer is, where it came from, and exactly how much of the fire is drawn in detail.
  • The headline numbers stay on screen, bottom left, with every panel closed.
